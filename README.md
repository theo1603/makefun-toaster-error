A deadpan toaster error message: the crumb tray is full, and the toaster has been quietly eating its owner's mistakes for six months. One line, 70 characters, written by a deterministic Python program with no dependencies and no network.

## Run it

```sh
python3 main.py
```

`main.py` writes the error message to `/output/entry.txt`.
